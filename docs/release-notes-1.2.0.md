# Nuvexa 1.2.0 — Release Notes

## Highlights

- Refreshed the app with a unified premium Material 3 design system across Home, Tools, Settings, Favorites, History, onboarding, PDF, OCR, image tools, calculators and shared components.
- Added an optional rewarded-ad flow: complete a rewarded ad and choose a share destination to unlock 60 minutes without banner or interstitial ads.
- Kept the existing banner and interstitial advertising model unchanged outside the earned ad-free window.
- Improved PDF/OCR/image feedback states, loading states, empty states, previews and error presentation.
- Improved navigation consistency and activated the user's selected default start screen.
- Removed duplicate interstitial exit handling so tool exits use one consistent ad decision path.
- Improved light/dark visual consistency and shared spacing, cards, buttons, inputs, results and dialogs.

## Release identifiers

- Version name: 1.2.0
- Version code: 7
- Application ID: com.nuvexa.app

## Validation

Release preparation requires the repository CI to pass unit tests, Android lint, debug APK, signed release APK and signed release AAB builds.
